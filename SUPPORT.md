# Support

DPAgent is an open-source, local-first project. Public support is best-effort through GitHub issues and pull requests.

## Where To Ask

- Bugs and regressions: open a GitHub issue with version, OS, Node.js version, config shape, toolset, and reproduction steps.
- Feature requests: open a GitHub issue with the workflow, expected outcome, and why existing toolsets or skills are not enough.
- Security issues: follow [SECURITY.md](SECURITY.md). Do not publish exploit details in a public issue first.

## Support Boundary

- There is no hosted DPAgent service or uptime SLA from this repository.
- Maintainer-only release gates may depend on private provider credentials or local browser setup.
- Public contributors are expected to run the closest local checks, not every maintainer release gate.
- Shell, MCP, remote access, and `full-access` support assumes the user owns and trusts the local machine and workspace.

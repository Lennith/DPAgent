# DPAgent User Guide

Use this skill when the user needs product-level DPAgent guidance rather than code changes.

## Workflow

1. Read `references/user-guide.md` for the current packaged guide.
2. Use the diagrams under `assets/user-guide/` when the user asks for UI explanation or shareable documentation.
3. Explain features in plain language first, then mention exact buttons or settings.
4. Do not invent configuration paths. Use placeholders such as `<workspace-dir>`, `<agent-dir>`, `<dpagent-host>`, and `<port>` unless the user gives an actual environment value.
5. For current behavior, prefer this guide plus live project docs over older chat memory.

## Coverage

- DPAgent installation and first setup.
- Main chat UI, composer controls, TB/TC/TR filters, file mentions, model selection, session Fork, Arena, Plan Mode, and Ralph loop.
- Mobile access and share-link usage.
- External agents and bundled agents.
- User-facing skills: debug info, update, agent creation, share client, ASR setup, hook builder.
- Common troubleshooting and safety notes.

## Output Style

Answer as a user guide writer: concrete, short steps, no internal implementation jargon unless the user asks for it.

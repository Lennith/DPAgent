# Playbook Index

Playbooks define commands, operational procedures, release gates, publishing steps, and handoff checklists.

Playbooks do not own product requirements, feature behavior, runtime protocols, or source module ownership. They can link to those layers when a procedure depends on them.

## Boundary
- Put reproducible commands, gate evidence rules, and handoff checklists here.
- Put internal mirror, Gerrit, or private registry procedures in [internal docs](../internal/README.md).
- Put user install and startup explanations in [guide](../guide/README.md).
- Put product requirements in [PRD](../prd/README.md).
- Put feature behavior in [design](../design/README.md).
- Put technical contracts in [spec](../spec/README.md).
- Put source ownership in [code](../code/README.md).

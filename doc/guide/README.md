# Guide Index

Guide documents are user-facing operating material. They explain how to install,
start, operate, and troubleshoot DPAgent.

Guides do not own product requirements, feature behavior, technical protocols,
or source ownership. They link to those layers when a user needs deeper detail.

## Documents
- [User guide](user-guide.md)
- [MiniMax Agent to DPAgent migration](minimax-migration.md)

## Boundary
- Put install, startup, first-use, and troubleshooting material here.
- Put product goals in [PRD](../prd/README.md).
- Put feature behavior in [design](../design/README.md).
- Put runtime contracts in [spec](../spec/README.md).
- Put source ownership in [code](../code/README.md).
